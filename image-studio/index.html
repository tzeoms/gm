Frequently Asked Questions

Are my images uploaded to a server?

No. Every Image Studio tool processes your image entirely inside your own browser using the HTML5 Canvas API. Your file never leaves your device, and nothing is stored or transmitted anywhere.

Do I need to create an account to use these tools?

No account is required. All five tools are free to use directly, with no sign-up or watermark.

What image formats are supported?

Image Studio accepts JPG, PNG, and WEBP files for upload, and the Converter tool can export to any of those three formats.

Is there a file size limit?

Yes, uploads are limited to 25MB per image to keep processing fast and reliable in your browser.

Will the AI Image Upscaler use real AI enhancement?

Currently the upscaler uses high-quality canvas-based resizing. See the upscaler page for details on how AI-enhanced upscaling can be integrated in the future.
